# Research Lab - Usage Manual

## Prerequisites Installation
*(One time setup per device)*

1. Install [Visual Studio Code](https://code.visualstudio.com/) (Not Visual Studio)
2. Install [miniforge3](https://github.com/conda-forge/miniforge) for environment management
3. Restart the terminal
4. Create virtual environment:
   ```bash
   conda create --name research_lab python=3.10
   ```
5. Activate the environment:
   ```bash
   conda activate research_lab
   ```
6. Install Python packages:
   ```bash
   pip install -r requirements.txt
   ```

## Getting Started
*(Run these steps every time before working on the project)*

1. Open Visual Studio Code
2. Open the project using **File > Open Folder** or **File > Open Recent**
3. Open Terminal from **View > Terminal**
4. Activate the Python environment:
   ```bash
   conda activate research_lab
   ```
5. You're all set! 🎉
